# 🚀 Quickstart: Query TimescaleDB with LangChain + Ollama

This project demonstrates how to connect **LangChain**, **TimescaleDB**, and **Ollama (LLaMA)** to query time-series data using natural language. Everything runs locally, free of API costs, and is reproducible with the `uv` build tool.

---

## 📌 Features
- **Natural language queries** → SQL → results
- **TimescaleDB** for time-series storage (e.g., market data, IoT, logs)
- **LangChain SQL Agent** to translate plain English into SQL
- **Ollama (LLaMA)** as the local LLM backend (no OpenAI key needed)
- **`uv` build tool** for clean, reproducible Python environment

---

## 1️⃣ Setup
Install dependencies with `uv`:
```bash
pip install uv
uv venv
uv pip install langchain langchain-community psycopg2-binary
```

Install Ollama and pull the model:
```bash
ollama pull llama3
```

Ensure TimescaleDB is running and accessible, e.g. via Docker:
```bash
docker run -d \
  --name timescaledb \
  -e POSTGRES_USER=ts_user \
  -e POSTGRES_PASSWORD=ts_pass \
  -e POSTGRES_DB=ticks \
  -p 5432:5432 \
  timescale/timescaledb:latest-pg15
```

---

## 2️⃣ Usage
Run a natural language query:
```bash
uv run main.py 'how many 1 min candles are there for PLTR on 2025-08-07'
```

Example flow:
- Input: `"how many 1 min candles are there for PLTR on 2025-08-07"`
- SQL generated by LangChain:
  ```sql
  SELECT COUNT(*) FROM candles
  WHERE symbol = 'PLTR' AND time >= '2025-08-07' AND time < '2025-08-08'
  AND interval = '1 minute';
  ```
- TimescaleDB executes query.
- Ollama formats the response.
